# ADR-0007: 阶段 3 删除语义、判定滑窗与出境口径

- 状态：Accepted（Haipeng）
- 日期：2026-09-30
- 关联：ADR-0004（K8s 集群）、ADR-0005（参数基线）、ADR-0006（阶段 2 工件纪律）、路线图 §5 阶段 3、规格书 §3.2/§9.3/§9.4、架构 §5.10、配套 [`01_详细设计.md`](../01_详细设计.md)、[`02_工程设计执行方案.md`](../02_工程设计执行方案.md)

## 背景

阶段 3（真实用户验证）工程实施完成 S1–S5（157 passed）。三类暂定数字与口径
需要一个统一的 ADR 锚点（路线图 §1.2 数字纪律：暂定值挂 ADR 与校准路径）：
备份滚动窗口、判定滑窗、数据出境策略。这些问题不固化会阻塞 Gate 3 判定与
知情同意书披露的一致性。

## 决策

### D1: 备份滚动窗口 = 30 天（spec §9.3 暂定值的固化）

append-only 事件表（L0/L1）中已删记忆的内容片段按 **30 天滚动备份窗口**
自然消亡，备份加密管理：

- 来源类别 (b) 工程地板（非法律意见）；校准路径 = 法务确认后冻结；
- 该语义已写入四法域同意模板 `data_deletion` 条款（`data/consent/`）；
- 一票否决第 5 条口径不变：**在线系统全介质零残留**（`user_erase` 自动验证
  `ir_recoverable`）；备份窗口只覆盖 append-only 日志的诚实披露部分。

### D2: 判定滑窗 ≥200 条（spec §3.2 的 Gate 判定抽样）

记忆错误率的 Gate 判定用**滑动窗口合并样本 ≥200 条**：

- 来源类别 (a) 统计功效推算：n=200、p=5% 时 CI 半宽约 ±3pp，可支撑 ≤5% 判定；
- n=50 的单周样本（CI ±6pp）**只能做趋势监测，永不用于 Gate 判定**——
  monitor 与 judge 两套抽样在 `src/lifeos/dogfood/metrics.py` 分离实现
  （`judge_memory_error_rate` 低于 200 条 fail-closed 抛 `JudgeWindowError`）；
- 校准路径：预注册时冻结；实测方差大则上调（新 ADR，不原地改）。

### D3: 数据出境口径 = 真人数据仅流经本地模型或境内合规 Provider（spec §9.4）

简化策略：Provider A（云端）受托处理协议未签署前，真人 cohort 的
Provider 白名单 = 本地 vLLM：

- API 层配置断言：白名单外 Provider 绑定请求拒绝（`/model/switch` 403，
  `PROVIDER_WHITELIST = {local-vllm, none}`）；
- Tier 比例目标不变：≥80% 调用走 Tier-1 本地模型（报告断言，
  `build_weekly_report` fail-closed）；
- 校准路径：Provider A 合规路径结论出来后重审（新 ADR）。

## 后果

- 三类暂定口径全部获得 ADR 锚点，Gate 3 判定的输入可复核；
- monitor/judge 抽样分离使"周样本误判"结构性不可能（fail-closed）；
- 出境白名单在 API 层强制，真人数据泄露面收敛到本地推理节点；
- 全部决策保留校准路径：法务确认 / 预注册冻结 / Provider 合规结论任一到位
  即触发重审。
