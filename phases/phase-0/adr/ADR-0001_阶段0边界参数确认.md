# ADR-0001：阶段 0 边界参数确认

- 状态：**待决策层签署**（本文档由 Phase 0 Day 1 创建，参数已从规格书 §1.2 抄录，签署行为本身是 Gate 0 前置动作）
- 日期：2026-09-（签署时补全）
- 关联：路线图 §0、规格书 §1.2、§9.6

## 决策

Phase 0 全部评测材料与工程口径锁定为以下边界参数；**任一变更必须重开本 ADR 并重排路线图**。

| # | 参数 | 取值 | 影响 |
|---|---|---|---|
| 1 | 评测语言 | **中文为主，全部评测材料中文编写并锁定**（规格书 §9.6 四条理由：控制变量/团队与市场/标注成本/材料效度） | gold set、探针、场景全部中文；英文是 Gate 3 后的 v1 议题 |
| 2 | 部署形态 | 单机 Docker Compose，多 Life Instance 共库，per-life 串行事件队列 | 全部 SQL 谓词强制带 `life_id`（Day 1 起执行，后补成本远高于先做） |
| 3 | 合规管辖区 | 多法域：中国大陆（PIPL）为主，扩展新加坡 PDPA / 香港 PDPO / 澳门 8/2005；义务自阶段 3 起 | 阶段 0 仅需：`ConsentRecord` 含 `jurisdiction/locale` 字段并建表 |
| 4 | 盲测口径 | 总样本 n≥50 下限、被试内配对、预注册功效核算 | 阶段 0 无动作，仅记录口径 |
| 5 | 文献基线 | `adadmic_innovation_v0.9.1.md`（2026-08-05），季度重跑检索式 | 阶段 0 无动作 |
| 6 | 范围排除 | 不做运动控制、不做产品交互界面 | `BehaviorIntent.modality` 仅为提示性枚举，无运动学参数 |
| 7 | 权威数据源 | PostgreSQL 16（+pgvector）唯一权威源；其他存储只做可重建缓存 | docker-compose 只含 postgres（pgvector 镜像）；Embedding 向量列推迟到阶段 1 选型后（见 01 文档 §3.3） |

## 后果

- 阶段 0 的 15 实体 Schema、事件协议、隔离测试全部按上述参数设计；
- 中文锁定意味着阶段 0 的人工编写材料（50 事实 / 30 场景）必须为中文（03 文档 §3.6）；
- 多实例隔离是「第一天就做对」项，不是优化项。
