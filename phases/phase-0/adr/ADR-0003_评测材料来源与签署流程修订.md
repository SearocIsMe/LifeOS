# ADR-0003：评测材料来源与签署流程修订（AI 起草 + 来源记录 + 独立审核 + 具名负责人审定）

- 状态：**Accepted（决策层采纳，2026-09-15）**
- 决策人：项目决策层（用户）
- 关联：`phases/phase-0/03_核心事实集与行为场景编写规范.md` §1/§2/§5、`phases/phase-0/02_工程设计执行方案.md` AC-09/W3-1、`phases/phase-0/README.md` 状态表、路线图 §2「50 条核心事实集是人工编写的」句、规格书 §9.2
- 触发材料：《LifeOS_Phase0_评审与80条候选材料.md》（AI 候选池 80 条 + 流程修订建议）

## 背景

1. 现行规范（03 文档 §1.2/§1.3）要求核心事实集与行为场景**必须人工编写**，LLM 不得产出终稿，注册强制双人互审签署（author ≠ reviewer）。
2. 2026-09-15，决策层明确要求以 AI 起草候选材料；产出为 80 条候选（50 事实 + 30 场景，draft.1 → draft.2），其文件头、逐条 notes 与 review 块均诚实自声明「未人工编写、未互审、未签署；不得据此宣称 AC-09 或任何 Gate 通过」。
3. 候选池机械校验（lifeos.goldset.validator，2026-09-15）：结构全部通过（配额 8/10/10/8/7/4/3 精确命中；30 场景 6 意图×5 全覆盖；唯一缺失 = 签署）。
4. 《评审与80条候选材料》论证：人工编写不是测量有效性的逻辑必要条件；真正须防止的是**答案源于被测输出、据成绩反向改题、评测答案泄漏进运行上下文、生成器与裁判共同偏差**；责任链可以通过「真实记录 AI 来源 + 具名负责人审定并承担发布责任」实现，前提是不把 AI 草稿略改后冒充纯人工原创。

## 决策

采纳双路径材料流程，本 ADR 优先于 03 文档现行条款：

- **P1 人工编写路径**（原流程，保持不变）：人工起草 → 双人交叉互审 → 仲裁 → 双人签署 → 注册。
- **P2 AI 起草 + 审定路径**（新增）：
  1. **AI 起草**：完整记录来源（模型/会话标识；无法获得时如实记 `unknown`，禁止猜测）；草稿版本链留痕（draft.1 → draft.2）；
  2. **独立质疑式审核**：审核侧先隐藏参考答案与 intent_target 做盲审（自行作答、找歧义、推演期望意图；规则缺失必须输出「不可判定」），两遍法（先盲答后对照）；审核标识、输入输出哈希与逐条结论留痕；
  3. **确定性校验**：validator 全量通过（结构/配额/唯一性/中文占比）；
  4. **具名负责人逐条审定**：负责人对**每一条**做出 采用/修改后退回/否决 的审定结论并签署（真实姓名 + 日期）；
  5. **注册冻结**：review 块 `author` 记起草来源（如 `AI-draft@unknown/draft.2`），`reviewer` 记具名负责人；**两者不得相同，且不得以任何模型名冒充人类签署**；
- **材料使用红线（继承并强化）**：参考答案/期望意图不得进入被测系统上下文；评测答案与运行记忆物理隔离；保留一份未用于调试的独立保留集（候选池 50 条为最小工程集，反复调参后不得宣称独立泛化）；生成器与裁判的模型相关性在报告中披露。
- **范围**：本 ADR 仅覆盖 core_facts 与 behavior_scenario 两类材料的来源与签署流程；gold set 的判定口径、阈值、统计规范不变。

## 与既有文档的关系

- 03 文档 §1.2「循环论证」四条理由降级为**风险陈述**（其缓解措施即 P2 四道工序）；§1.3 禁止清单改写为「禁止无来源记录、禁止无审定签署、禁止把 AI 草稿略改后冒充纯人工原创」；§2 增加 P2 流程；§5.1-9 签署语义按上表解释。
- 02 文档 AC-09 的签署检查（author/reviewer 非空且不等）语义不变，P2 下 reviewer 必须为具名负责人。
- 路线图 §2「50 条核心事实集是人工编写的」一句与规格书 §9.2 相关表述**自本 ADR 起按 P2 路径执行**，待下一版本修订时正式改写原文（本 ADR 为准）。
- README 复选框「人工编写 + 双人互审」改写为「材料编制完成（P1 或 P2）+ 签署」。

## 后果与剩余动作

- 候选池（draft.2，50+30）可进入 P2 流程第 2～5 步；
- **注册前置条件**：具名负责人完成逐条审定并提供真实署名（姓名 + 日期）——本 ADR 不签署、不注册、不改变 Gate 0 的 INCOMPLETE 状态；
- 独立保留集：从候选池或后续增补中划出（建议 ≥10 条事实 + ≥6 个场景），P2 审定时一并圈定；
- 若负责人审定中否决/修改条目，修订版重新过 validator 后再签署。
