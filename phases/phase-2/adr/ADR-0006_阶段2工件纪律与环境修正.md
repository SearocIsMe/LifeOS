# ADR-0006: 阶段 2 工件纪律与环境修正

- 状态：Accepted（Jiang Haipeng）
- 日期：2026-09-29
- 关联：ADR-0005（阶段 1 环境适配与参数基线）、路线图 §4 阶段 2、架构设计 §9、配套 [`02_工程设计执行方案.md`](../02_工程设计执行方案.md)

## 背景

阶段 2（三 Demo + 四基线 + continuity 模拟器 + 盲测/成本/伦理工件）实施中。
本 ADR 记录实施过程中发现的三类决策：pytest 路径修正、S5 工件纪律、
验收证据位置。这些问题不解决会阻塞验收 case 复跑与 Gate 2 判据。

## 决策

### D1: pytest `pythonpath` 修正（环境修正）

沙箱环境未安装 `lifeos` 包（`src` 布局，[`pyproject.toml`](../../../pyproject.toml)
`[tool.setuptools.packages.find] where=["src"]`），`tests/test_acceptance_tier_a.py`
导入 `lifeos.cli` 失败。修复方式：

- 在 `pyproject.toml` `[tool.pytest.ini_options]` 增加 `pythonpath = ["src"]`；
- 不改为可编辑安装（`pip install -e .`），避免沙箱网络依赖；
- 效果：全量回归 111 passed（含阶段 0/1 既有用例无回归）。

### D2: S5 工件纪律（先冻结、先提交、后施测）

四件工件统一落 [`doc/templates/`](../../../doc/templates/)，顺序纪律沿用阶段 0
诚实纪律（spec §9.4 / §15）：

| 工件 | 路径 | 顺序不变量 |
|---|---|---|
| 预注册分析计划 | `doc/templates/preregistered_analysis_plan_template.yaml` | `frozen_at < first_data_collected_at`，顺序错→数据作废 |
| 多法域知情同意模板（zh） | `doc/templates/consent/consent_template_zh.yaml` | CN/SG/HK/MO，CN 主审、其余合规自查 |
| 伦理申请模板 | `doc/templates/ethics/ethics_application_template.yaml` | `submitted_at < first_data_collected_at` |
| 盲测施测问卷（zh） | `doc/templates/questionnaire/blind_test_questionnaire_zh.yaml` | 冻结后施测；注意力检查未过→作答作废 |

- 多法域口径：**CN 主审**（主要部署地），SG/HK/MO 合规自查（规格书 §9.4）；
- 材料统一中文，不引入新语言载体； recruits n≥50，被试内配对 + 拉丁方。

### D3: 验收证据位置

  `phases/phase-2/reports/ambiguous_queue.json`。

### D4: 云端计费与告警参数（README 遗留项关闭）

负责人给定参数（2026-09-29），作为版本化常数管理（`BILLING_RULES_VERSION = "billing-v1"`），
任何调整均为新版本而非静默编辑（Gate 0 #4）：

| 项 | 值 |
|---|---|
| 单价 | 0.4 人民币 / 1 百万 token（prompt + completion） |
| 告警线 | 累计总额超过 100 人民币即报警，以后每增长 100 人民币报警一次（100、200、300…） |

- 边界口径：``超过`` 为严格大于——恰好等于 N×100 不触发，越过才触发；
- 聚合口径：Invocation 聚合 P50/P95 折算每千次成本（Gate 2 判据 #5）；
- 实现位置：`src/lifeos/gateway/billing.py`（`cost_cny` / `BillingAggregator` / `per_thousand_calls_cny`）；
- 对应单测：`tests/test_billing.py`（8 passed，含 100/200/300 三级步进与严格边界）；
- 全量回归：119 passed（含阶段 0/1 既有用例无回归）。

### D5: 阶段 2 末状态追记（2026-09-29，负责人授权记录）
