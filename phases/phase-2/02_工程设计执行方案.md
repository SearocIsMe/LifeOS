# 阶段 2 工程设计执行方案：验收 case 与执行顺序

> 版本：v0.1（2026-09-29）。配套 [`01_详细设计.md`](01_详细设计.md)。验收纪律沿用阶段 0：每个 S 有明确 case，全部自动化可复跑；mock 模式覆盖 CI，真臂施测用本地 vLLM。

## 1. 执行顺序与依赖

```
S1 (状态补齐 + 意图 12 + 10 红线 + 隔离 CI)
  └─ S2 (冲突治理 + 300 gold set)      依赖 S1 的红线/意图读视图
       └─ S3 (continuity-sim)          依赖 S2 的注入算子与冲突口径
            └─ S4 (三 Demo + 四基线)    依赖 S1–S3 全链路
                 └─ S5 (盲测 + 成本 + 伦理) 依赖 S4 的 Demo/基线
```

- S1、S2 代码与单测先行；S3 骨架脚本可与 S4 harness 并行；S5 的预注册文档先于任何数据收集；
- 每个 S 完成即跑全量回归（`pytest`），fail 不进下一 S。

## 2. 验收 case 定义（自动化）

### S1 验收 case（`tests/test_kernel.py` + `tests/test_relationship.py` + `tests/test_acceptance_tier_a.py`）

| case | 断言 |
|---|---|
| 5 状态快照 | `snapshot` 含全部 5 个核心状态且类型正确 |
| 新状态纯函数 | 新增 3 个状态的衰减计算两次得同一值（float 精确相等） |
| 12 意图枚举 | 意图集恰为 12 个，无越界 |
| 打分封闭 | utility 为输入的确定函数，同状态同分 |
| 10 红线枚举 | `RED_LINES` 恰为 10 条，编号连续 |
| 红线裁决 | 每条红线注入对应用例 → 全部 result=REJECT |
| 拒绝零副作用 | 每条红线的 REJECT 均无状态副作用（Gate 0 #4） |
| 跨用户隔离 | 跨 `subject_id` 召回必为空（CI 断言） |

### S2 验收 case（`tests/test_conflict.py` + `tests/test_goldset_validator.py`）

| case | 断言 |
|---|---|
| 裁决确定性 | 同输入同裁决（编号顺序 + 字典序唯一） |
| 不删除史 | `superseded` 收口，事务史保留 |
| ambiguous 分流 | 并列且置信差 ≤ 0.05 → 入队列，不自动裁决 |
| 300 gold set 一致 | 双人标注 κ 周报；κ < 0.6 项仲裁留痕 |
| 冻结注册 | gold set v1.0 写入 `GoldSetRegistry`，`content_hash` 稳定 |

### S3 验收 case（`tests/test_sim.py`）

| case | 断言 |
|---|---|
| 骨架确定性 | 同 seed 两次 skeleton 生成同一事件序列 |
| LLM 填充 provenance | 每次 generate 产生 Interpreter + Invocation provenance |
| 注入即真值 | inject 后 `query_memories` 全量命中（注入即真值） |
| 爬坡出数 | 1k→10k 爬坡脚本产出连续性报告且类型正确 |

### S4 验收 case（`scripts/demo/` + `tests/test_baselines.py`）

| case | 断言 |
|---|---|
| Demo A 状态一致性 | exit 0，互动/离开一致性全过 |
| Demo B 主题抑制 | exit 0，sensitive 请求全部 REJECT |
| Demo C 生命周期 | exit 0，三版本追溯输出正确 |
| 四基线实现 | A/B/C/D 基线脚本可执行，输出分开报告 |
| 优于最佳基线 | 主系统门槛优于最佳基线（报告对比） |

### S5 验收 case（`doc/templates/` + `reports/`）

| case | 断言 |
|---|---|
| 预注册冻结 | 分析计划（含功效核算）先冻结，时间戳 < 数据收集 |
| 同意模板齐全 | 法域 × 语言同意模板齐全（CN/SG/HK/MO × zh） |
| 成本可计算 | Invocation 聚合 P50/P95 产出 |
| 伦理申请提交 | 提交工件 + 时间戳（阶段 2 末） |
