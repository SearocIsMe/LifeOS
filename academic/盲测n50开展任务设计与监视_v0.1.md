## 三A、B4 招募与收数：目的 / 输入 / 输出 / 文档格式 / 验收标准（四问澄清）

### 1. 目的（要做什么）

从真实人群合规地招募盲测被试并收集配对判断数据，产出 B5 分析所需的**原始作答数据集**——H3（用户可感知连续性）的唯一证据来源。具体三件事：

1. **招募**：发招募材料（含批准号 + 同意书）→ 筛查（三筛 fail-closed）→ 入组，n≥50 有效被试 + 候补 1.5×；
2. **施测**：每名被试经施测通道完成 8 片段 × 4 臂的配对判断（注意力检查 + 拉丁方顺序）；
3. **监测**：收数全程计数（周报 cadence），一周 n<30 触发降级，n≥50 才停。

### 4. 验收标准（B4 完成定义，全部可复核）

| # | 标准 | 复核方式 |
|---|---|---|
| 1 | 有效 n≥50（`effective_n`：注意力通过 + ≥1 条非作废作答） | `recruitment_monitor.json` 计数与 `responses.jsonl` 行数对账 |
| 2 | 每臂判断数 ≥50（被试内设计） | 按臂聚合 `chose` 非空且非作废的计数 |
| 3 | 全部作答含签署同意记录（无同意无作答，fail-closed） | `ConsentRecord` 与 `responses.jsonl` 的 subject_id 对账 |
| 4 | 剔除仅依据预注册规则（无事后剔除） | `exclusions.json` 的 rule 字段 ⊆ 预注册剔除标准原文 |
| 5 | 呈现顺序符合拉丁方（平衡性可复核） | `order_seq` 重放 `latin_square_order` 比对 |
| 6 | 注意力检查未过者全部作答已作废且不计入有效 n | `voided=true` 行与 `effective_n` 对账 |
| 7 | 监测不静默：降级触发（如发生）有 `degraded=true` + 原因记录 | `recruitment_monitor.json` 与周报 cadence 对账 |
| 8 | 匿名化：作答数据不含直接标识符（spec §9 数据治理） | 字段审计（只有化名 subject_id） |

**B4 完成线**：标准 1–8 全部满足 → 移交 B5 分析（bootstrap CI / 双编码 κ / 达门槛判定）。n<50 → 不判定，继续招募（B4.2 降级路径）。

**环境前提（2026-10-01 修复留痕）**：`.venv` 由 uv 管理（无 pip），最初未装 fastapi/uvicorn → `ModuleNotFoundError: fastapi`。修复：

```bash
/root/.local/bin/uv pip install --python .venv/bin/python fastapi "uvicorn[standard]" httpx pydantic PyYAML
```

修复后 venv 启动冒烟通过（fastapi 0.142.2，页面 200 + API 返回 LIFE-BT-002/24 trials）。**教训：uv 管理的 venv 没有 pip，装依赖用 `uv pip install --python .venv/bin/python`。**

**负责人两条命令**：

```bash
# 1. 启动服务（一条命令；决策门前仅局域网，不暴露公网，arch §5.10）
python3 scripts/serve_blindtest.py
```

服务启动后打印访问 URL（实测：`http://192.168.10.203:8200/blindtest?survey=LIFE-BT-002`）。

```bash
# 2. （可选）指定问卷实例与落库目录
python3 scripts/serve_blindtest.py --port 8200 --out-dir reports/blindtest
```

**被试操作**：浏览器打开负责人下发的 URL → 同意页（批准号 + 三项确认勾选 + email 输入用于防重）→ 签署并开始 → 24 题配对判断（拉丁方顺序 + 强制二选一 + 理由框）→ 自动提交落库（`reports/blindtest/responses.jsonl` 匿名化）。

- URL 中的 `?survey=LIFE-BT-002` 决定加载哪份问卷实例（`survey/LIFE-BT-002.json`：24 trials 真臂文本 + 该被试的拉丁方顺序）；
- 服务冒烟已验证：页面 200 含批准号、API 经服务返回 LIFE-BT-002/24 trials；
- 决策门前仅局域网（不暴露公网），多法域招募时由负责人在各部署地内网启动。
