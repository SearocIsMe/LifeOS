## PPT 1：LifeOS 是什么，为什么值得投（价值 + 证据）

**标题**：LifeOS——AI 陪伴角色的长期身份连续性运行时：技术空白已验证，工程已收口

**一句话**：身份连续性由外部化状态决定而非模型权重——换模型从「重大事故」降级为「配置变更」。

**左栏：三层价值主张（商业方看）**

| 听众 | 价值 |
|---|---|
| C 端用户 | 情感资产不丢失：关系动力学版本化 + 记忆双通道召回，换模型/降档/国产化替换不"换人" |
| 平台方 | 规避供应商锁死：≥80% Tier-1 本地化推理（固定权重），换模型降级为配置变更 |
| 监管侧 | 红线即代码：10 条 Policy 红线自动化用例 + 两级删除语义——可审计合规证据，与诱导付费型竞品的伦理差异线 |

**右栏：技术先进性（教授看）**

- **空白已查证**（季度守卫）：「跨模型切换 × 周月级长时程 × 带记忆多会话」连续性基准无人做过（文献基线 2026-08-05，PersonaGym/InCharacter/CharacterEval 均为单模型）；
- **三层真实交付**：契约层（15 实体 + L0/L1/L2 + `deterministic_commit` 同 L2 重放 100%）/ 治理层（10 红线 + TOKI + 四法域 Consent + 擦除不可恢复）/ 评测层（gold set 冻结 + 八项指标 + 四基线 + 60 份问卷）——**254 tests passing，零回归**；
- **⭐ H1 真臂证据**（`phases/phase-1/reports/h1_real_arm_report.json`）：30 case / 28 一致，h1_score=0.933 ≥ 90% 门槛，双 vLLM 真模型——"换模型它还是它"有工程证据；
- 对标差异线：Character.AI（单模型绑定）/ Letta/MemGPT（假定模型固定）/ Portable Agent Memory（迁移状态但不测保真度）——LifeOS 八项指标 + H1 真臂补上量化评测。

**底部：依赖外部条件（显式声明）**：伦理 ✅ 2026-ETH-00001 approved / 算力 Gate 0 闭环 / 公网 frp/headscale 配置交付 / 全开源栈零许可成本。

## PPT 2：产品化路线与投资回报（路径 + 定位 + 决策）

**标题**：从研发到 commercial ready：整体约 55–60%，第一阶段回报 6 个月可见

**左栏：三条商业路径（商业方看）**

| 路径 | 故事 | 时间 | 硬门 |
|---|---|---|---|
| A 基准与协议开源 → 行业标准占位 | 引用基座 + 获客（类 Chroma/Supabase） | 12–18 个月 | 盲测数据齐全 → arXiv 报告 + 协议草案 |
| B 托管服务 → C 端 companion 载体产品 | 会员/增值，红线透明为信任卖点 | 18–30 个月 | **Gate 3**（盲测门槛 + 无高危操纵 + 成本 P95 达标） |
| C 企业支持 → B 端角色连续性基础设施 | 品牌角色/数字员工/国产化迁移 | 18–36 个月 | 协议草案 + 企业运维（per-life 队列已交付） |

**右栏：当前进度定位（教授看，独立评估）**

- **三段口径**（本文新增，不照搬路线图）：研发收口 ~95% → 证据与标准 ~40%（全为执行项：公网对接/收数/标注/施测/报告）→ 商业立项 ~0%（有意等待 Gate 3 硬门与 margin 条款——**是纪律不是落后**）；
- **里程碑表**：M3 发布上线（配置交付，对接待执行）→ M4 收数 n≥50 → Gate 3 真实判定（fail-closed 结构）→ M5 arXiv + 协议草案（数据齐全后 6 个月内）；
- **诚实声明**：路线图只估算研发人月（24–40，误差 ±30%）；载体产品/托管/企业支持需商业化团队另立估算——**这是下一个核算项，本文不虚构数字**。

**底部：三个决策建议（请求两类听众共同决策）**

1. **授权节奏**：按"第二段完成（收数 + Gate 3 判定）→ 第三段立项"逐级授权，第一阶段资源锚定 M3/M4 执行与文献守卫；不一次性批准第三段；
2. **时间条款**：arXiv 报告与协议草案设"数据齐全后 6 个月"时间条款（开源占位价值随时间衰减，"空白被占"有真实信号）；约定收数 4 周 n<30 触发降级审查；
3. **margin 参与设定**：研究所方直接参与"单实例月推理成本上限"设定（**这是投资条款不是技术参数**），P50/P95 实测分布作为 dogfood 交付验收项。

**一句话收尾**：技术风险已释放（三层交付 + 文献查证守卫），剩余风险在执行与统计而非设计——第一阶段回报锚定基准开源与标准占位，消费与 B2B 立项等待 Gate 3 硬门，按里程碑逐级授权并直接参与 margin 设定。
