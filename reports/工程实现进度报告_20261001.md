- PostgreSQL 16 + pgvector 容器、alembic 0001 首迁移、tier B 2/2 PASS。

### 阶段 1（全部完成）

- Kernel 惰性衰减纯函数（同 (t0,x0,t) 必得同值）+ Relationship 更新（clip[0,1] + 版本化）；

- Gateway 双 Provider（Qwen3.6-35B 常态 / GLM-5.3-Flash 按需）+ provenance 逐笔落库；

- **H1 真臂 30 case / 28 一致（h1_score=0.933 ≥ 90% 门槛），双 vLLM 真模型（Qwen3.6-35B vs GLM-5.3-Flash），guided decoding + prompt_hash 留痕**。

### 阶段 2（全部完成）

- 预注册分析计划冻结（α=0.05/power=0.8/n=50/被试内配对/拉丁方）+ 盲测问卷/同意/伦理工件（ADR-0006 D2 顺序不变量）。

### 阶段 3（工程侧完成，2026-10-01）

- **治理链上线**：用户擦除（物理删除，全介质清除 + 索引自动重建 + 权威/向量/全文三通道不可恢复验证——一票否决第 5 条自动化断言固化于 `EraseReport.ir_recoverable`）；权利四操作通道（查阅/更正必须走 L2 管线 RED-09/删除/导出双人审批）；Consent 激活（敏感项单独同意 PIPL/撤回联动 revoke → 停止处理 + 自动擦除/未成年人排除 <18）；
- **Memory OS v1**：EmbeddingOutbox Worker（claim PENDING → embed → 只更新 status/retry/embedded_at/model_version 四个可变字段；失败重试_count+1 保持 PENDING，超 3 次翻 FAILED；幂等 DONE 永不重claim；**embedding 失败永不阻塞权威事实**）+ 双通道召回（cosine 排序 vector 通道 + SQL 降级 sql_fallback，召回永不中断，life_id/subject_id 谓词硬过滤）；
- **Kernel v1 参数校准闭环**：标注入数（decay/delta 观察）→ λ 闭式反演（残差 0 vs floors）→ floors 兜底（fail-safe）；
- **三引擎适配器**：Concordia/AgentSociety/GenerativeAgents episode → L0 走 committed 管线 + round-trip 验证套件；
- **Life Studio v0 调试台**：FastAPI 子应用（state/intents/replay/outbox views）；
- **frp/frp ffmpeg/frp 三件套**：frp 内网穿透配置交付（frp 原方案，存档对照）+ **headscale 穿透方案落地**（K8s 部署 + headscale 基础）；
- **B4.1 候招募者材料**：登记表模板（填空 S1–S4 + 同意 C1–C3）+ `recruitment_intake` 预注册规则自动筛查 + **60 份问卷实例**（survey/LIFE-BT-000..059.json：化名编号 + 拉丁方 + 24 trials 真臂素材 + 注意力检查 + consent 不预填）；
- **B3.1 施测页**：同意页（批准号+三项确认）→ 配对判断页（1b 分组呈现 1/8 场景页 + 3 步比较 + 强制二选一+无法回答 + 理由 200 字/grey 提示）→ 匿名化落库（JSONL + 幂等）；
- **基础设施**：IP 访问限流（每 IP 每窗口 ≤10 次，超限 429）+ IP 唯一性检测（已提交 → footbar 提示完成，不进提问页）+ 用户真实 IP 解析链（X-Forwarded-For 最左/X-Real-IP/兜底 socket 对端）+ 倒推按钮（答案保留）+ token 占位（部署时替换）。
